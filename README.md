
# Ola Electric Market Analysis Dashboard

## 📊 Project Overview
This project analyzes Ola Electric's declining market share despite rapid growth in India's EV market.

## 🔍 Key Insights
- EV market grew from ~70K to ~128K registrations
- Ola’s sales dropped significantly
- Competitors like TVS & Bajaj gained momentum
- Problem is execution, not demand

## 📈 Dashboard Features
- Market growth trend
- Ola sales decline trend
- Competitor comparison

## 🛠 Tools Used
- Tableau Public
- Google Sheet

## Data Source 
- Vahan portal
- Assumption
- Time Period(Apr 2025-Mar 2026)

## 📌 Conclusion
Ola is losing market share due to internal issues while competitors are scaling efficiently
